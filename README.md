# Ресурспак Hide&Seek Revival 2

Ресурспак карты «Прятки» для сервера Hide&Seek Revival 2 (Paper 1.21.11).

Содержит 240 моделей AnimatedJava, которые использует мир: анимации батута,
чёрной дыры, книги, конфет, карт и другие.

## Скачать

Файл лежит в разделе Releases: `HideSeek-ResourcePack.zip`

Сервер раздаёт его автоматически при входе.
